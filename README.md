# SNS運用管理ダッシュボード

2026-09-30時点のローカル8792番の画面・集計処理を登録したものです。
上部の「生産活動」タブと左側の「事業所一覧」は削除済みで、ホームの集計表・SNS別詳細・推移を維持しています。既存の内部ルートは互換性のため残しています。

## 起動

Node.js 22以上で、`npm test` によりテスト、`npm start` により起動します。
URLは http://127.0.0.1:8792/#home です。同じポートで別のサーバーが起動中なら、`PORT` 環境変数に空きポートを指定してください。

実データの接続先は `config.example.json` を複製した `config.local.json` に設定します。台帳ID・実データ・認証情報はリポジトリに含みません。UIL大通のSNS接続先は未確認のため、数値を推測せず未接続として表示します。

## データ保護

台帳はGETによる読取専用です。元データの更新・削除・初期化・共有権限変更は行いません。設定ファイルはHTTP配信せず、ブラウザーへ台帳IDを返しません。既存の内部生産活動ルートには利用者明細が含まれるため、サーバーはこのPC内からのみ接続できる設定です。

GitHubへのソース登録と、外部PCでの公開運用は別です。GitHub PagesだけではNodeサーバーのAPIは動作しません。このリポジトリの登録では公開ホスティングを設定していません。
